# pandasx

[![npm](https://img.shields.io/npm/v/pandasx)](https://www.npmjs.com/package/pandasx)
[![CI](https://github.com/gftf2011/pandasx/actions/workflows/ci.yml/badge.svg)](https://github.com/gftf2011/pandasx/actions/workflows/ci.yml)
[![Docs](https://github.com/gftf2011/pandasx/actions/workflows/docs.yml/badge.svg)](https://gftf2011.github.io/pandasx/)

[pandas](https://pandas.pydata.org/)-style `Series` and `DataFrame` for Node.js, written in TypeScript.

📖 **Documentation: [gftf2011.github.io/pandasx](https://gftf2011.github.io/pandasx/)** — [getting started](https://gftf2011.github.io/pandasx/guide/getting-started), [coming from pandas](https://gftf2011.github.io/pandasx/guide/coming-from-pandas), guides with runnable examples and the full [API reference](https://gftf2011.github.io/pandasx/api/).

🧪 **[Examples](https://github.com/gftf2011/pandasx/tree/main/examples)**: 20 runnable scripts covering every feature, from `Series` basics to an end-to-end sales report.

- **Columnar, typed storage**: numbers and dates in `Float64Array`, booleans in `Uint8Array`, categories in `Int32Array`.
- **Faithful to the pandas API**, with camelCase names (`sort_values` → `sortValues`, `read_csv` → `readCsv`).
- **Checked against real pandas**: 214 parity cases (`npm run parity`) plus fixtures written by pandas 3.1.
- **No required dependencies.** Excel, Parquet, Feather and HDF5 use optional packages that only the people who need them install.

```bash
npm install pandasx
```

Requires Node.js 22.23.4+, 24.22.1+ or 26.12.1+: earlier releases have a Brotli decoder vulnerable to [CVE-2026-111497 (Node2Shell)](https://gftf2011.github.io/pandasx/guide/io#brotli-and-cve-2026-111497-node2shell).

## Example

```ts
import * as pd from 'pandasx';

const df = new pd.DataFrame({
  region: ['SP', 'RJ', 'SP', 'MG', 'RJ', 'SP'],
  product: ['coffee', 'coffee', 'tea', 'coffee', 'tea', 'coffee'],
  quantity: [10, 4, 0, 7, 12, 25],
  price: [12.5, 13, 8, 11.9, 7.5, 12.5],
});
// or: const df = pd.readCsv('sales.csv', { parseDates: ['date'] });

const summary = df
  .query('quantity > 0')
  .assign({ revenue: (d) => d.get('quantity').mul(d.get('price')) })
  .groupby('region')
  .agg({ revenue: 'sum', quantity: ['mean', 'max'] })
  .sortValues(['revenue', 'sum']);

console.log(summary);
//         revenue  quantity
//             sum      mean  max
// region
// MG         83.3       7.0    7
// RJ        142.0       8.0   12
// SP        437.5      17.5   25
```

## From pandas to pandasx

Python overloads `[]` and operators. JavaScript can't, so those forms become methods:

| pandas (Python) | pandasx |
|---|---|
| `df['a']`, `df[['a','b']]`, `df[mask]` | `df.get('a')`, `df.get(['a','b'])`, `df.get(mask)` |
| `df['c'] = v` | `df.set('c', v)` |
| `df.loc['x', 'a']`, `df.loc['x':'z']` | `df.loc('x', 'a')`, `df.loc(pd.slice('x', 'z'))` |
| `df.loc[mask, 'a'] = 0` | `df.setLoc(mask, 'a', 0)` (also `setIloc`, `setAt`, `setIat`) |
| `s + 1`, `s == 1`, `(a > 1) & ~b` | `s.add(1)`, `s.eq(1)`, `a.gt(1).and(b.not())` |
| `df.query('a > 1 and b == "x"')` | `df.query('a > 1 and b == "x"')` (same syntax) |
| `df.groupby('k')['v'].sum()` | `df.groupby('k').get('v').sum()` |
| `df[('price', 'min')]` (MultiIndex columns) | `df.column(['price', 'min'])` |
| `pd.option_context('display.precision', 2)` | `pd.optionContext({ 'display.precision': 2 }, () => ...)` |
| `df.plot.bar()` (matplotlib) | `df.plot.bar()` → SVG |

The complete mapping is in [Coming from pandas](https://gftf2011.github.io/pandasx/guide/coming-from-pandas).

## Differences from pandas

The main ones: `[]` and operators become methods, binary I/O is asynchronous, datetimes have millisecond resolution, column labels are unique strings, and plots are SVG with no secondary y axis. The full list is in [Differences from pandas](https://gftf2011.github.io/pandasx/guide/differences).

## Performance

Six common operations on 1 million rows against the other JavaScript dataframe libraries (Apple M2, Node.js 24), median time, lower is better:

| Task | pandasx | Arquero | danfo.js | Data-Forge |
|---|---:|---:|---:|---:|
| `groupby` (1,000 groups) | **132 ms** | 202 ms | 701 ms | 3.04 s |
| `merge` (inner join) | **155 ms** | 219 ms | 1.04 s | 527 ms |
| `sortValues` | **125 ms** | 721 ms | 168 s | 2.11 s |
| `filter` | **38 ms** | 41 ms | 512 ms | 112 ms |
| `valueCounts` | **55 ms** | 125 ms | 116 ms | 357 ms |
| `readCsv` | 1.17 s | **975 ms** | 2.32 s | 3.29 s |

pandasx is the fastest at 7 of the 10 tasks (filtering, sorting, group by, joins, arithmetic, statistics, `valueCounts`); Arquero is faster at CSV parsing and danfo.js at writing CSV. All ten tasks, both sizes and the method are in [Benchmarks](https://gftf2011.github.io/pandasx/guide/benchmarks); the code is in [`bench/`](bench).

### Documentation

The site in [`docs/`](docs) is built with VitePress; the API reference is generated from the source by TypeDoc.

```bash
cd docs && npm ci
```

```bash
npm run dev
```

Every ` ```ts run ` block in the guides is executed and its output written into the ` ```text ` block after it. After changing the library or an example, refresh the outputs with `npm run examples` (in `docs/`) and commit them: the build (`npm run build`) fails if any documented output is stale.

Each push to `main` deploys the site to [GitHub Pages](https://gftf2011.github.io/pandasx/) through the **Docs** workflow (`.github/workflows/docs.yml`); it can also be run by hand from **Actions → Docs → Run workflow**.

## Releasing

Bump `version` in `package.json` (e.g. `npm version patch`), push to `main`, then run **Actions → Publish to npm → Run workflow**. The workflow fails if that version is already on npm. It authenticates with npm [Trusted Publishing](https://docs.npmjs.com/trusted-publishers): on npmjs.com the package lists `gftf2011/pandasx` with workflow `publish.yml` as its trusted publisher, so no token is stored.
